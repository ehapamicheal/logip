# 📊 Logip Dashboard
This is a Team Performance Dashboard UI built with a modern and minimal design. The purpose of the dashboard is to allow team members and managers to monitor task progress, performance trends, and overall team efficiency over time.

## 🔍 Overview
The dashboard includes:

Greeting Section: Personalized welcome message with the current date.

Key Metrics:

Tasks Finished

Time Tracked

Efficiency Score (with percentage change indicators)

Performance Graph: Interactive line chart comparing current vs previous month's working hours.

Current Tasks:

Task titles with progress status (In Progress, On Hold, Done)

Time logged on each task

User Profile Widget: Quick access to contact, video call, and message options.


## 🛠 Tech Stack 
HTML5

CSS3

JavaScript

## 📌 Note: This is a frontend-only implementation. No backend or real-time functionality is connected in this version.
